# Boilerplates: For Loops

Batch operations and iteration for DevOps automation.

## Available Boilerplates

### 1. Multi-Region Deployer
**File**: `boilerplate_multi_region_deployer.sh`

**Purpose**: Deploy Lambda to multiple AWS regions

**Usage**:
```bash
./boilerplate_multi_region_deployer.sh
```

---

### 2. Server Inventory Scanner
**File**: `boilerplate_server_inventory_scanner.sh`

**Purpose**: Asset discovery via network scan

**Usage**:
```bash
./boilerplate_server_inventory_scanner.sh
```

---

### 3. Docker Image Builder
**File**: `boilerplate_docker_image_builder.sh`

**Purpose**: Multi-platform image builds (amd64, arm64)

**Usage**:
```bash
./boilerplate_docker_image_builder.sh
```
