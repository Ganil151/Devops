# Real-World Projects Showcase

This directory contains complete, production-ready project examples. These are designed to show how different DevOps tools (Terraform, K8s, CI/CD, React, Django) work together in a single ecosystem.

---

## 🏗️ Project Catalog

### 1. [Call Center CRM (Python/React)](./My_Project/call_center_crm/README.md)
A full-stack application for managing call center operations. 
- **Frontend**: React.js with Analytics Dashboards.
- **Backend**: Python/Django REST Framework.
- **Database**: PostgreSQL.
- **DevOps**: Dockerized and prepared for AWS deployment.

### 2. [Next.js & Django API](./DjangoReactApp/README.md)
A modern boilerplate for building high-performance web applications with a Python backend.
- **Frontend**: Next.js (Server-side rendering).
- **Backend**: Django API with JWT authentication.

### 3. [Advanced Microservices](./Microservices/README.md)
Enterprise-grade microservice patterns for Kubernetes and EKS.
- **Service Mesh**: Istio integration.
- **Observability**: Prometheus/Grafana monitoring dashboards.

### 4. [Multi-Tier Enterprise Infrastructure](./Multi_Tier_Apps/README.md)
A standard 3-tier architecture (Web, App, DB) provisioned using Terraform on AWS.
- **Networking**: VPC with Public/Private subnets.
- **Compute**: Autoscaling Groups with Load Balancers.

---

## 🚀 How to Use These Projects
1. **Clone the Repo**: Each project is standalone.
2. **Follow the Local README**: Every project contains specific instructions for environment setup and deployment.
3. **Use as Templates**: These are designed to be "skeleton" projects that you can extend for your own production needs.
