# Scripts & Code Assets

This directory serves as the technical heart of the repository. It contains thousands of lines of automation code, configuration templates, and operational scripts.

---

## 📁 Key Directories

- **[Ansible](./Ansible/)**: Playbooks and roles for fleet management.
- **[Kubernetes](./Kubernetes/)**: Raw manifests, charts, and operator logic.
- **[Terraform](./Terraform/)**: HCL modules for multi-cloud provisioning.
- **[Python for DevOps](./Py4DevOps/)**: Python-based automation and SDK examples.
- **[Shell Scripting](./Shell-Scripting/)**: Advanced bash logic and tool installers.
- **[Docker](./Dockers/)**: Optimized Dockerfiles and multi-stage build templates.

---

## 🛠️ Usage
These scripts are intended to be studied and used as templates. Every script should be reviewed for environment-specific variables (like IP addresses, regions, or credentials) before execution.
