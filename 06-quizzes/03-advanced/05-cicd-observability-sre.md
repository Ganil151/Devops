## 🏗️ Part 1: CI/CD & DevSecOps

### [Intermediate] In DevSecOps, what does the term "Shift Left" refer to?
- [ ] A) Moving application logic to the front-end.
- [ ] B) Implementing security testing and audits earlier in the development lifecycle.
- [ ] C) Moving servers to a different cloud region.
- [ ] D) Using only Bash scripts instead of specialized tools.

<details>
<summary>Click to Reveal Answer</summary>

**Correct Answer:** B
**Why?** Detecting a vulnerability during the code/build phase is significantly cheaper and safer than finding it in production.
**Certification Alignment:** AWS Certified DevOps Engineer Professional (Security)
</details>

## 📊 Part 2: Observability & SRE

### [Junior] What is the difference between Prometheus and Grafana?
- [ ] A) Prometheus is for UI, Grafana is for data.
- [ ] B) Prometheus is the time-series database/collector, while Grafana is the visualization layer.
- [ ] C) Prometheus only works for Linux, Grafana for Windows.
- [ ] D) They are the same tool.

<details>
<summary>Click to Reveal Answer</summary>

**Correct Answer:** B
**Why?** Prometheus scrapes metrics and stores them. Grafana queries those stores to create beautiful dashboards. They are the "Dynamic Duo" of modern monitoring.
**Certification Alignment:** SRE Best Practices
</details>
