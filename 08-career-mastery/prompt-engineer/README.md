## 📁 Complete Prompt Library

### 🎯 Phase 1: Skill Development & Portfolio

#### 1. **Skills Gap Analyzer** (`skills-gap-analyzer.md`)
**Purpose:** Identify critical skill gaps and generate personalized 90-day learning roadmaps  
**Use When:** Planning your skill development or preparing for a career transition  
**Output:** Gap analysis + week-by-week study plan + resource recommendations + progress tracking  
**Impact:** Focus on the 20% of skills that deliver 80% of career value

#### 2. **Portfolio Project Evaluator** (`portfolio-project-evaluator.md`)
**Purpose:** Validate project ideas and optimize your GitHub profile for recruiter attention

**Impact:** Build projects that actually get you interviews (not tutorial hell)

## 💡 Pro Tips for Using These Prompts

### Tip #1: Chain Prompts for Compound Effects
Don't use prompts in isolation. Example flow:
1. Use **Skills Gap** to identify you need Kubernetes skills
2. Use **Portfolio Evaluator** to validate your K8s project idea
3. Build the project, then use **Recruiter Prompt** to add it to your resume
4. Use **LinkedIn Optimizer** to share a blog post about your project

### Tip #2: Save & Version Your Outputs
Create a folder structure:
```
career-artifacts/
├── 2026-02/
│   ├── resume-v1-recruiter-feedback.md
│   ├── resume-v2-ats-tested.pdf
│   ├── linkedin-about-section-draft.md
│   ├── skills-roadmap-90days.md
│   └── cold-email-templates.md
```

Track your evolution over time.

### Tip #3: Iterate, Don't Accept First Output
AI prompts are conversation starters. After the first response:
- Ask: "Can you make this more technical and less marketing-y?"
- Ask: "What are 3 alternative approaches to this?"
- Ask: "What red flags might a hiring manager see in this answer?"

### Tip #4: Customize the "Role" Section
Each prompt has a "Role: Act as..." section. Customize it:
- For startups: "...with experience at Series A-C startups"
- For FAANG: "...who has hired at Google, Meta, and Amazon"
- For specific industry: "...specializing in HealthTech/FinTech/etc."

### Tip #5: Use AI Assistants Differently
- **ChatGPT (GPT-4):** Best for resume optimization, cold emails (creative writing)
- **Claude:** Best for technical interview prep, skills gap analysis (detailed reasoning)
- **Gemini:** Best for research (integrates with Google search)

Try the same prompt on different assistants and compare outputs.

## ⚠️ Common Anti-Patterns (Don't Do This!)

### ❌ Using Prompts as One-Time Magic Bullets
Prompts are tools for iteration, not instant solutions. Use them in conversation.

### ❌ Copy-Pasting AI Output Verbatim
AI generates starting points. You must customize with YOUR specific experiences and voice.

### ❌ Only Using Prompts When Desperate
Start building relationships and optimizing your profile 6-12 months before you need a job.

### ❌ Ignoring the "Act As" Role Definition
The role specification primes the AI's perspective. If you get generic output, you didn't specify a strong enough role.

### ❌ Not Measuring Results
Track before/after metrics. If a prompt doesn't improve your outcomes, adjust it.

## 📜 Prompt Engineering Best Practices

Each prompt in this collection follows these principles:

1. **Clear Role Definition** - Primes the AI with specific expertise
2. **Structured Output Requirements** - Defines exactly what format you need
3. **Context-Rich Inputs** - Placeholder for YOUR specific data
4. **Measurable Outcomes** - Expects metrics, not vague statements
5. **Iteration Hooks** - "Next Steps" sections for follow-up prompts

When creating your own prompts, use these as templates.
