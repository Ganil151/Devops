## 🎯 Workflows by Career Stage

### 📚 **Student / Career Changer (0-6 months)**

**Goal:** Build foundational knowledge + 1-2 portfolio projects

**Week 1-2:**
1. Read [DevOps Persona](./01-devops-persona/readme.md)
2. Study [Tool Landscape](./02-the-tool-landscape/readme.md)
3. Run [Skills Gap Analyzer](./prompt-engineer/skills-gap-analyzer.md)

**Month 1-3:**
4. Follow 90-day learning plan from Skills Gap Analyzer
5. Build 1 project using [Portfolio Guide](./06-portfolio-guide/readme.md)
6. Set up LinkedIn using [LinkedIn Optimizer](./prompt-engineer/linkedin-optimizer.md)

---

### 🔍 **Actively Job Hunting**

**Goal:** 5+ interviews in 30-60 days

**Week 1:**
1. Optimize resume: [Resume Engineering](./07-resume-engineering/readme.md)
2. Run [Recruiter Prompt](./prompt-engineer/recruiter-prompt.md) for 3+ target jobs
3. Fix formatting: [ATS Stress Test](./prompt-engineer/ats-stress-test.md)

**Week 2-4:**
4. Set up LinkedIn: [LinkedIn Optimizer](./prompt-engineer/linkedin-optimizer.md)
5. Start networking: [Cold Outreach Prompt](./prompt-engineer/networking-cold-outreach.md)
6. Send 10-15 cold emails/week

**Week 5-8:**
7. Prepare for interviews: [Interview Mastery](./08-interview-mastery/readme.md)
8. Practice STAR stories: [Final Round Prompt](./prompt-engineer/final-round-interview.md)

---

### 🎤 **Interview Prep Mode**

**Goal:** Pass technical screens + tell compelling stories

**Week 1-2:**
1. Study [Technical Deep Dives](./08-interview-mastery/01-technical-deep-dives/) (focus on job's tech stack)
2. Complete [Mock Interview Scripts](./08-interview-mastery/00-MOCK-INTERVIEW-SCRIPTS.md)

**Week 3-4:**
3. Practice STAR method: [Behavioral Guide](./08-interview-mastery/03-behavioral-star-method/)
4. Run [Final Round Interview Prompt](./prompt-engineer/final-round-interview.md)
5. Record yourself answering questions (Loom)

---

### 💼 **Offer Negotiation**

**Goal:** +10-20% above initial offer

**Day 1:**
1. Read [Salary Negotiation Guide](./09-salary-negotiation/readme.md)
2. Run [Salary Negotiation Prompt](./prompt-engineer/salary-negotiation.md)

**Day 2-3:**
3. Research market data (Levels.fyi, Blind)
4. Draft counter-offer email using prompt templates

**Day 4-7:**
5. Send counter-offer
6. Negotiate via call (not just email)
7. Get final offer in writing

---

### 🌱 **Employed, Planning Ahead (6-12 months)**

**Goal:** Position for promotion or better opportunities

**Monthly:**
1. Update [Skills Gap Analyzer](./prompt-engineer/skills-gap-analyzer.md) quarterly
2. Build 1 project/quarter: [Portfolio Evaluator](./prompt-engineer/portfolio-project-evaluator.md)
3. Engage on LinkedIn weekly: [LinkedIn Optimizer](./prompt-engineer/linkedin-optimizer.md)

**Quarterly:**
4. Review [Strategic Roadmap](./05-strategic-roadmap/readme.md) for next level
5. Update resume with new projects/metrics

## 🚨 Top 5 Mistakes (AVOID THESE!)

### ❌ 1. "I'll apply when I'm 100% ready"
→ **Fix:** Apply at 70% qualified. Growth happens through interviews.

### ❌ 2. Not negotiating because "I'm junior"
→ **Fix:** ALWAYS negotiate. Even $5k adds up to $50k+ over career.

### ❌ 3. Tutorial hell with no portfolio projects
→ **Fix:** Build 1 project per skill learned. Projects > certifications.

### ❌ 4. Ignoring soft skills / communication
→ **Fix:** 40% of senior work is communication. Practice now.

### ❌ 5. Spray-and-pray job applications
→ **Fix:** 10 tailored applications > 100 generic ones.
