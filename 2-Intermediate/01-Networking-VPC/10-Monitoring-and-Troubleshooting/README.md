# Monitoring and Troubleshooting

Visibility is the foundation of a reliable cloud network. This module covers the tools and strategies for monitoring traffic, analyzing connectivity, and diagnosing complex networking issues in AWS.

## 🚠 Modules Breakdown

### 1. [VPC Flow Logs: Network Visibility](01-VPC-Flow-Logs-Network-Visibility/README.md)
Master the basics of network metadata. Learn how to capture, analyze, and store flow logs for security and troubleshooting.

### 2. [Reachability Analyzer: Network Insights](02-Reachability-Analyzer-Network-Insights/README.md)
Learn to use intent-based static analysis to identify blocking components (SGs, NACLs, Routes) without sending a single packet.

### 3. [Traffic Mirroring: Deep Packet Inspection](03-Traffic-Mirroring-Deep-Packet-Inspection/README.md)
Go beyond metadata. Capture full packet payloads for security forensics, IDS/IPS integration, and advanced troubleshooting.

### 4. [Common Troubleshooting Scenarios](04-Common-Troubleshooting-Scenarios/README.md)
A practical guide to the most frequent AWS networking "gotchas," from stateless NACL behaviors to DNS resolution failures.

### 5. [Advanced Monitoring Tools](05-Advanced-Monitoring-Tools/README.md)
Explore enterprise-grade tools like AWS Network Manager, Network Access Analyzer, and VPC Lattice monitoring.

---

## 📈 Learning Objectives
-   Configure and query VPC Flow Logs using CloudWatch and Athena.
-   Debug point-to-point connectivity using Reachability Analyzer.
-   Implement packet capture sessions with Traffic Mirroring.
-   Apply a structured troubleshooting sequence to resolve VPC connectivity issues.
-   Leverage automated reasoning tools for network security compliance.
