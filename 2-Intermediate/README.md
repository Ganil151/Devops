# Intermediate Level: Automation & Orchestration Roadmap

![Intermediate DevOps](https://img.shields.io/badge/Level-Intermediate-orange?style=for-the-badge&logo=kubernetes)

Welcome to the **Intermediate Level**. This is where we shift from manual tasks and foundational concepts to building scalable, automated, and self-healing systems. 

You will transition from "managing a server" to "orchestrating a cluster" using the industry's most powerful tools.

---

## 🗺️ The Intermediate Curriculum

This level is organized into a tiered journey across **16 specialized modules**. Many modules include curated **YouTube Lessons** for visual reinforcement and hands-on learning.

---

### 🌱 Phase 1: Foundations (Intermediate Tier)

#### 1️⃣ [02-Linux](./01-Phase-1/02-Linux/README.md)
**Intermediate System Administration & Security**
- Master systemd, signals, and process lifecycle
- SSH hardening, key management, and tunneling
- System logs, diagnostic tools, and kernel observability

#### 2️⃣ [01-Networking](./01-Phase-1/01-Networking/README.md)
**Advanced Cloud Networking, VPC Architecture & Security**
- VPC fundamentals, subnetting, and CIDR blocks

#### 3️⃣ [07-Repository-Management](./01-Phase-1/07-Repository-Management/README.md)
**Enterprise Version Control & Repository Architecture**
- Git, GitLab, Bitbucket, and Azure DevOps Repos
- Enterprise branching models (GitFlow, Trunk-based)
- 📚 Interview Questions and Consolidation Summary

#### 4️⃣ [08-Databases](./01-Phase-1/08-Databases/README.md)
**SQL, NoSQL & Database DevOps Practices**
- PostgreSQL, MySQL, MariaDB, and Amazon RDS
- NoSQL scaling (MongoDB, Redis, DynamoDB)
- Backup strategies, replication, and disaster recovery

#### 5️⃣ [04-Runbooks-Procedures](./01-Phase-1/04-Runbooks-Procedures/README.md)
**Automated Remediation & Operational Excellence**
- Writing effective Standard Operating Procedures (SOPs)
- Auto-remediation patterns and self-healing strategies
- Incident management and response workflows

## 🎯 Learning Objectives

By the end of this level, you will be able to:

✅ **Configure** - Use centralized configuration management tools (Terraform, Ansible, Helm) for infrastructure and applications

✅ **Automate** - Build "Commit-to-Cloud" pipelines with security scanning and quality gates

✅ **Orchestrate** - Deploy and manage multi-service applications on Kubernetes clusters

✅ **Secure** - Implement API Gateways, JWT authentication, and network security policies

✅ **Observe** - Debug production issues using comprehensive monitoring and logging systems

✅ **Optimize** - Apply FinOps principles and AI-driven automation to streamline operations
