# Intermediate Level: Automation & Orchestration Roadmap

Welcome to the **Intermediate Level**. This is where we shift from manual tasks and foundational concepts to building scalable, automated, and self-healing systems. 

You will transition from "managing a server" to "orchestrating a cluster" using the industry's most powerful tools.

---

## 🗺️ The Intermediate Curriculum

This level is organized into a progressive journey across 14 specialized modules. Each module now includes a curated **YouTube Lessons** collection for visual reinforcement.

1.  **[00-Runbooks-Procedures](./00-Runbooks-Procedures/README.md)**: Moving from manual hacks to automated remediation.
2.  **[01-Networking-VPC](./01-Networking-VPC/README.md)**: Advanced cloud networking, peering, and subnets.
3.  **[02-Automation](./02-Automation/README.md)**: Python for DevOps and scripting patterns.
4.  **[03-Configuration-Tools](./03-Configuration-Tools/README.md)**: IaC and configuration management (Terraform, Ansible, Chef, Helm, Cloud-Init).
5.  **[04-CI-CD](./04-CI-CD/README.md)**: Advanced delivery pipelines (Jenkins, GitLab, GitLab Runner).
6.  **[05-Kubernetes](./05-Kubernetes/README.md)**: Orchestrating container fleets (Pods, Services, Deployments).
7.  **[06-Databases](./06-Databases/README.md)**: Scaling managed data stores (RDS, DynamoDB, Aurora).
8.  **[07-Observability-Foundations](./07-Observability-Foundations/README.md)**: Metrics, Logs, and the Four Golden Signals.
9.  **[08-API-Gateways-Security](./08-API-Gateways-Security/README.md)**: Traffic control, JWT auth, and Nginx/Kong.
10. **[09-Cloud-Engineering](./09-Cloud-Engineering/README.md)**: Cloud patterns, Landing Zones, and architectural best practices.
11. **[10-Prompt-Engineering](./10-Prompt-Engineering/README.md)**: AI-driven troubleshooting and runbook generation.

14. **[13-FinOps](./13-FinOps/README.md)**: Cost optimization, allocation, and Savings Plans.

---

## 🎯 Final Learning Objectives
By the end of this level, you will be able to:
1.  **Configure**: Use centralized configuration management tools (Terraform, Ansible, Helm) for infrastructure and applications.
2.  **Automate**: Build "Commit-to-Cloud" pipelines with security scanning and quality gates.
3.  **Orchestrate**: Deploy and manage multi-service applications on Kubernetes clusters.
4.  **Secure**: Implement API Gateways, JWT authentication, and network security policies.
5.  **Observe**: Debug production issues using comprehensive monitoring and logging systems.
6.  **Optimize**: Apply FinOps principles and AI-driven automation to streamline operations.
