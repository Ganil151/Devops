# HCL & IaC Best Practices

Welcome to the advanced study of Infrastructure as Code. This module focuses on the principles, patterns, and security practices required to run Terraform at an enterprise scale.

## 📚 Learning Path

1.  **[IaC Principles](./01-IaC-Principles/README.md)**: Idempotency, immutability, and declarative workflows.
2.  **[Project Structure](./02-Project-Structure/README.md)**: Scaling from single-file to multi-module.
3.  **[Environment Management](./03-Environment-Management/README.md)**: Isolation strategies (Workspaces vs. Directories).
4.  **[Configuration Patterns](./04-Configuration-Patterns/README.md)**: DRY, Composition, and Dynamic Blocks.
5.  **[Version Control Integration](./05-Version-Control-Integration/README.md)**: Git strategies and peer review.
6.  **[CI/CD Pipeline Integration](./06-CI-CD-Pipeline-Integration/README.md)**: Automating init, plan, and apply.
7.  **[Testing Strategies](./07-Testing-Strategies/README.md)**: Linting, scanning, and unit testing.
8.  **[Documentation Standards](./08-Documentation-Standards/README.md)**: Automated READMEs and variable help.
9.  **[Security Practices](./09-Security-Practices/README.md)**: State protection and secret management.
10. **[Compliance & Governance](./10-Compliance-and-Governance/README.md)**: Policy as Code (OPA/Sentinel).
