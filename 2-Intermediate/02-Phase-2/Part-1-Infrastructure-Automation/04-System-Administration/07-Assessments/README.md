## 🚀 How to Prepare

- **Hands-on is King**: Do not just read. Open a VM/Terminal and try to expand an LVM partition or write a systemd unit.
- **Fail Fast**: Learn to read `/var/log/audit/audit.log` and `journalctl` quickly. In a crisis, speed of diagnostics is everything.
- **Explain the "Why"**: In interviews, don't just give the command. Explain why you are using it (e.g., "I'm using `iostat` specifically to check for I/O wait times").
