# 🧮 Arithmetic Challenges

## Challenge 1: Space Calculator
Write a script that:
1.  Takes a total disk size (GB) and used space (GB) as arguments.
2.  Calculates the percentage used using `bc`.
3.  Prints a warning if used > 90%.
4.  Prints "OK" otherwise.

## Challenge 2: Average Calculator
Write a script that:
1.  Accepts an unlimited number of arguments (integers).
2.  Loops through them to calculate the Sum.
3.  Calculates the Average (Sum / Count) handling decimals (e.g., sum is 10, count is 3 -> 3.33).
4.  **Tip**: Use `$#` for the count and `$@` for the loop.
