## 🎯 Reorganization Rationale

**Why Commands were moved to Position 02:**
- **Immediate Application**: Students can practice commands as they learn theory.
- **Hands-on First**: Reduces cognitive load by seeing the tool in action early.
- **Reduced Friction**: Essential CLI reference is now at the top of the learning path.
- **Industry Aligned**: Matches HashiCorp's recommended "Learn by Doing" approach.

## 📖 Recommended Study Order

### Week 1: Basics & CLI Essentials
- **Day 1-2**: `01-What-is-Terraform` - Understand the "Why" and "What."
- **Day 3-4**: `02-Commands` - Get comfortable with the CLI immediately.
- **Day 5**: `03-Core-Concepts` - Deep dive into Architecture & State.

### Week 2: Environment & Language
- **Day 1**: `04-Installation-and-Setup` - Configure your local machine.
- **Day 2-4**: `05-Configuration-Language` - Master the HCL syntax.
- **Day 5**: `06-Providers` - Understand the plugin system.

### Week 3: Infrastructure Blocks
- **Day 1-2**: `07-Resources` - Build your first resources.
- **Day 3-4**: `08-Variables-and-Outputs` - Make your code dynamic.
- **Day 5**: `09-Data-Sources` - Connect to existing infrastructure.

### Week 4: Professional Workflow & Practice
- **Day 1-2**: `10-Terraform-Workflow` - Implement industry best practices.
- **Day 3-4**: `11-Basic-Examples` - Complete hands-on projects.
- **Day 5**: `12-Provisioners` - Learn when (and when not) to use provisioners.
