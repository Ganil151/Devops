# API Gateways & Security (Intermediate)

As applications scale from single servers to microservices, how we manage, secure, and monitor APIs becomes more complex. This module covers the "Middle Layer" of API management, focusing on traffic routing, security tokens, and traffic control.

---

## 🗺️ Learning Path

This module is divided into 6 progressive phases:

1.  **[01-API-Gateway-Basics](./01-API-Gateway-Basics/README.md)**
    *   Routing, Aggregation, and Protocol Translation.
    *   Differences between Load Balancers and Gateways.
    *   Popular tools: Kong, Tyk, AWS API Gateway.

2.  **[02-Authentication-and-JWT](./02-Authentication-and-JWT/README.md)**
    *   Deep dive into JSON Web Tokens (JWT).
    *   OAuth2 and OpenID Connect (OIDC) flows.
    *   Security best practices for token management.

3.  **[03-Traffic-Control-and-Rate-Limiting](./03-Traffic-Control-and-Rate-Limiting/README.md)**
    *   Rate Limiting algorithms (Token Bucket, Leaky Bucket).
    *   Throttling and Circuit Breaker patterns.
    *   Protecting backend services from exhaustion.

4.  **[04-API-Documentation-and-Management](./04-API-Documentation-and-Management/README.md)**
    *   OpenAPI Specification (Swagger).
    *   API Lifecycle Management (Versioning, Deprecation).
    *   Testing with Postman.

5.  **[05-Interview-Questions-and-Quizzes](./05-Interview-Questions-and-Quizzes/README.md)**: Test your knowledge and prepare for job screenings.
6.  **[06-Real-Life-Scenarios](./06-Real-Life-Scenarios/README.md)**: Practical troubleshootng and architecture challenges.
7.  **[📺 YouTube Lessons](./Youtube_Lessons.md)**: Curated video tutorials for visual learning.

---

## 🎯 Final Objectives
By the end of this module, you will be able to:
1.  Explain the core role of an API Gateway in microservices.
2.  Validate and secure APIs using JWT and OAuth2 flows.
3.  Protect systems using Rate Limiting and Circuit Breakers.
4.  Design and document APIs using the OpenAPI standard.
5.  Troubleshoot production API issues through real-world scenarios.
6.  Prepare for technical interviews centered on API management and security.
