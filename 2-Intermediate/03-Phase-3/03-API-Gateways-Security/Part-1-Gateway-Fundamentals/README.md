# 🏗️ Part 1: Gateway Fundamentals

The API Gateway is the single entry point for all clients. This part covers why we need gateways, how they differ from simple load balancers, and the architectural patterns that make microservices manageable.

---

## 📂 Modules in this Part

### 1. [01-API-Gateway-Basics](./01-API-Gateway-Basics/README.md)
The foundation of modern traffic routing.
- **Routing & Reverse Proxy**: Mapping external paths to internal services.
- **Protocol Translation**: Converting HTTP/1.1 to gRPC or WebSockets.
- **Request Aggregation**: Combining data from multiple backends into one response.
- **Tooling**: Kong, Tyk, and AWS API Gateway.
