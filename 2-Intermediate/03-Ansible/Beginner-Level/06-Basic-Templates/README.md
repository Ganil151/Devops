# Ansible Templates

Complete guide to Ansible templates using Jinja2 for dynamic configuration file generation and content management.

## Template Basics

### What are Templates?

Templates in Ansible use the Jinja2 templating engine to generate dynamic content. They allow you to create configuration files, scripts, and other text-based content that adapts to different environments and variables.

### Template Structure
```jinja2
{# This is a comment #}
# Configuration file for {{ app_name }}
# Generated on {{ ansible_date_time.iso8601 }}

server_name = {{ server_name | default('localhost') }}
port = {{ app_port }}
debug = {{ debug_mode | lower }}

{% if ssl_enabled %}
ssl_certificate = {{ ssl_cert_path }}
ssl_private_key = {{ ssl_key_path }}
{% endif %}

{% for user in users %}
user_{{ loop.index }} = {{ user.name }}:{{ user.role }}
{% endfor %}
```

## Basic Template Usage

### Simple Template Example
```yaml
# playbook.yml
- name: Configure application
  hosts: webservers
  vars:
    app_name: myapp
    app_port: 8080
    debug_mode: false
  
  tasks:
    - name: Generate configuration file
      template:
        src: app.conf.j2
        dest: /etc/myapp/app.conf
        owner: appuser
        group: appgroup
        mode: '0644'
      notify: restart app
```

```jinja2
# templates/app.conf.j2
# {{ app_name }} Configuration File
# Generated by Ansible on {{ ansible_date_time.iso8601 }}

[application]
name = {{ app_name }}
port = {{ app_port }}
debug = {{ debug_mode | lower }}
host = {{ ansible_default_ipv4.address }}

[logging]
level = {% if debug_mode %}debug{% else %}info{% endif %}
file = /var/log/{{ app_name }}.log
```

### Template Module Parameters
```yaml
- name: Generate configuration with all options
  template:
    src: config.j2                    # Source template file
    dest: /etc/app/config.conf        # Destination path
    owner: appuser                    # File owner
    group: appgroup                   # File group
    mode: '0644'                      # File permissions
    backup: yes                       # Create backup of existing file
    force: yes                        # Overwrite existing file
    validate: 'nginx -t -c %s'        # Validation command
  notify: restart service
```

## Jinja2 Syntax

### Variables and Expressions
```jinja2
{# Variable substitution #}
Server name: {{ server_name }}
Port: {{ port_number }}

{# Expressions #}
Total memory: {{ ansible_memtotal_mb * 1024 }} KB
Percentage: {{ (used_space / total_space * 100) | round(2) }}%

{# Default values #}
Database host: {{ db_host | default('localhost') }}
Timeout: {{ timeout | default(30) }}

{# String operations #}
Uppercase name: {{ app_name | upper }}
Lowercase env: {{ environment | lower }}
```

### Conditionals
```jinja2
{# Simple if statement #}
{% if ssl_enabled %}
ssl_certificate = {{ ssl_cert_path }}
ssl_private_key = {{ ssl_key_path }}
{% endif %}

{# If-else statement #}
{% if environment == 'production' %}
log_level = warn
{% else %}
log_level = debug
{% endif %}

{# Multiple conditions #}
{% if ssl_enabled and ssl_cert_path is defined %}
# SSL Configuration
ssl_certificate = {{ ssl_cert_path }}
{% if ssl_key_path is defined %}
ssl_private_key = {{ ssl_key_path }}
{% endif %}
{% endif %}

{# Complex conditions #}
{% if ansible_os_family == 'RedHat' and ansible_distribution_major_version|int >= 8 %}
# RHEL 8+ specific configuration
systemd_service = true
{% elif ansible_os_family == 'Debian' %}
# Debian/Ubuntu configuration
systemd_service = {{ ansible_service_mgr == 'systemd' }}
{% endif %}
```

### Loops
```jinja2
{# Simple loop #}
{% for package in packages %}
{{ package }}
{% endfor %}

{# Loop with index #}
{% for user in users %}
user{{ loop.index }} = {{ user }}
{% endfor %}

{# Loop with conditions #}
{% for host in groups['webservers'] %}
{% if hostvars[host]['environment'] == 'production' %}
server {{ loop.index }} {{ hostvars[host]['ansible_default_ipv4']['address'] }}
{% endif %}
{% endfor %}

{# Dictionary loop #}
{% for key, value in database_config.items() %}
{{ key }} = {{ value }}
{% endfor %}

{# Loop variables #}
{% for item in items %}
Item {{ loop.index }} of {{ loop.length }}: {{ item }}
{% if loop.first %}(first item){% endif %}
{% if loop.last %}(last item){% endif %}
{% endfor %}
```

## Filters

### String Filters
```jinja2
{# Case conversion #}
{{ app_name | upper }}              # MYAPP
{{ app_name | lower }}              # myapp
{{ app_name | title }}              # Myapp
{{ app_name | capitalize }}         # Myapp

{# String manipulation #}
{{ message | replace('old', 'new') }}
{{ filename | basename }}
{{ path | dirname }}
{{ text | truncate(50) }}
{{ string | trim }}

{# String formatting #}
{{ "Hello %s" | format(name) }}
{{ "{0} version {1}".format(app_name, version) }}
```

### Numeric Filters
```jinja2
{# Math operations #}
{{ value | abs }}                   # Absolute value
{{ value | round }}                 # Round to integer
{{ value | round(2) }}              # Round to 2 decimal places
{{ values | sum }}                  # Sum of list
{{ values | min }}                  # Minimum value
{{ values | max }}                  # Maximum value

{# Number formatting #}
{{ large_number | filesizeformat }} # Human readable file size
{{ percentage | round(1) }}%        # Percentage with 1 decimal
```

### List Filters
```jinja2
{# List operations #}
{{ packages | length }}             # List length
{{ packages | first }}              # First item
{{ packages | last }}               # Last item
{{ packages | random }}             # Random item
{{ packages | sort }}               # Sorted list
{{ packages | unique }}             # Remove duplicates
{{ packages | reverse }}            # Reverse order

{# List joining #}
{{ packages | join(', ') }}         # Join with comma
{{ paths | join(':') }}             # Join with colon

{# List filtering #}
{{ numbers | select('odd') | list }}
{{ items | reject('undefined') | list }}
```

### Dictionary Filters
```jinja2
{# Dictionary operations #}
{{ config | list }}                 # Dictionary keys
{{ config | dict2items }}           # Convert to list of key-value pairs
{{ items | items2dict }}            # Convert from list to dictionary

{# Combining dictionaries #}
{{ dict1 | combine(dict2) }}        # Merge dictionaries
```

### Date and Time Filters
```jinja2
{# Date formatting #}
{{ ansible_date_time.epoch | strftime('%Y-%m-%d') }}
{{ ansible_date_time.iso8601 | to_datetime | strftime('%B %d, %Y') }}

{# Current date/time #}
Generated on: {{ ansible_date_time.date }}
Timestamp: {{ ansible_date_time.epoch }}
```

## Advanced Template Techniques

### Macros
```jinja2
{# Define macro #}
{% macro render_user(user) %}
[user_{{ user.name }}]
name = {{ user.name }}
email = {{ user.email }}
role = {{ user.role | default('user') }}
{% endmacro %}

{# Use macro #}
{% for user in users %}
{{ render_user(user) }}
{% endfor %}

{# Macro with default parameters #}
{% macro database_config(host='localhost', port=3306, name='mydb') %}
host = {{ host }}
port = {{ port }}
database = {{ name }}
{% endmacro %}

{{ database_config(host=db_host, name=db_name) }}
```

### Template Inheritance
```jinja2
{# base.conf.j2 - Base template #}
# Base configuration for {{ app_name }}
{% block header %}
# Default header
{% endblock %}

{% block main_config %}
# Main configuration goes here
{% endblock %}

{% block footer %}
# Generated by Ansible
{% endblock %}

{# app.conf.j2 - Child template #}
{% extends "base.conf.j2" %}

{% block header %}
# Custom application header
# Version: {{ app_version }}
{% endblock %}

{% block main_config %}
server_name = {{ server_name }}
port = {{ app_port }}
{% endblock %}
```

### Including Templates
```jinja2
{# main.conf.j2 #}
# Main configuration file
{% include 'database.conf.j2' %}
{% include 'logging.conf.j2' %}
{% include 'security.conf.j2' %}

{# database.conf.j2 #}
[database]
host = {{ db_host }}
port = {{ db_port }}
name = {{ db_name }}

{# logging.conf.j2 #}
[logging]
level = {{ log_level }}
file = {{ log_file }}
```

## Real-World Template Examples

### Nginx Configuration
```jinja2
# templates/nginx.conf.j2
user {{ nginx_user }};
worker_processes {{ nginx_worker_processes | default('auto') }};
pid /run/nginx.pid;

events {
    worker_connections {{ nginx_worker_connections | default(1024) }};
    use epoll;
    multi_accept on;
}

http {
    # Basic Settings
    sendfile on;
    tcp_nopush on;
    tcp_nodelay on;
    keepalive_timeout {{ nginx_keepalive_timeout | default(65) }};
    types_hash_max_size 2048;
    
    # MIME Types
    include /etc/nginx/mime.types;
    default_type application/octet-stream;
    
    # Logging
    access_log {{ nginx_access_log | default('/var/log/nginx/access.log') }};
    error_log {{ nginx_error_log | default('/var/log/nginx/error.log') }};
    
    # Gzip Compression
    {% if nginx_gzip_enabled | default(true) %}
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level {{ nginx_gzip_level | default(6) }};
    gzip_types
        text/plain
        text/css
        text/xml
        text/javascript
        application/javascript
        application/xml+rss
        application/json;
    {% endif %}
    
    # Virtual Hosts
    {% for vhost in nginx_vhosts %}
    server {
        listen {{ vhost.port | default(80) }};
        server_name {{ vhost.server_name }};
        root {{ vhost.document_root }};
        index {{ vhost.index | default('index.html index.htm') }};
        
        {% if vhost.ssl | default(false) %}
        listen 443 ssl;
        ssl_certificate {{ vhost.ssl_certificate }};
        ssl_certificate_key {{ vhost.ssl_certificate_key }};
        {% endif %}
        
        location / {
            try_files $uri $uri/ =404;
        }
        
        {% if vhost.locations is defined %}
        {% for location in vhost.locations %}
        location {{ location.path }} {
            {{ location.config | indent(12) }}
        }
        {% endfor %}
        {% endif %}
    }
    {% endfor %}
}
```

### Apache Virtual Host
```jinja2
# templates/vhost.conf.j2
<VirtualHost *:{{ vhost_port | default(80) }}>
    ServerName {{ server_name }}
    {% if server_aliases is defined %}
    {% for alias in server_aliases %}
    ServerAlias {{ alias }}
    {% endfor %}
    {% endif %}
    
    DocumentRoot {{ document_root }}
    
    <Directory {{ document_root }}>
        Options {{ directory_options | default('Indexes FollowSymLinks') }}
        AllowOverride {{ allow_override | default('All') }}
        {% if ansible_distribution_major_version|int >= 2.4 %}
        Require all granted
        {% else %}
        Order allow,deny
        Allow from all
        {% endif %}
    </Directory>
    
    {% if ssl_enabled | default(false) %}
    SSLEngine on
    SSLCertificateFile {{ ssl_certificate }}
    SSLCertificateKeyFile {{ ssl_private_key }}
    {% if ssl_certificate_chain is defined %}
    SSLCertificateChainFile {{ ssl_certificate_chain }}
    {% endif %}
    {% endif %}
    
    # Logging
    ErrorLog {{ error_log | default('/var/log/apache2/' + server_name + '_error.log') }}
    CustomLog {{ access_log | default('/var/log/apache2/' + server_name + '_access.log') }} combined
    
    {% if custom_config is defined %}
    # Custom configuration
    {{ custom_config | indent(4) }}
    {% endif %}
</VirtualHost>
```

```jinja2
max_connections = {{ mysql_max_connections | default(200) }}

thread_stack = {{ mysql_thread_stack | default('192K') }}
thread_cache_size = {{ mysql_thread_cache_size | default(8) }}

# Query Cache
{% if mysql_query_cache_enabled | default(true) %}

binlog_format = {{ mysql_binlog_format | default('ROW') }}

{% if mysql_replication_role == 'master' %}
# Master Configuration

{% elif mysql_replication_role == 'slave' %}
# Slave Configuration
relay-log = {{ mysql_relay_log | default('relay-bin') }}
read_only = 1
{% endif %}
{% endif %}
```

## Template Testing and Debugging

### Template Validation
```yaml
# Validate template syntax
- name: Generate and validate configuration
  template:
    src: nginx.conf.j2
    dest: /tmp/nginx.conf.test
  register: template_result
  check_mode: yes

- name: Validate nginx configuration
  command: nginx -t -c /tmp/nginx.conf.test
  when: template_result is changed
```

### Debugging Templates
```yaml
# Debug template variables
- name: Debug template variables
  debug:
    msg: |
      App name: {{ app_name }}
      Port: {{ app_port }}
      SSL enabled: {{ ssl_enabled }}
      Environment: {{ environment }}

# Generate template to temporary location for inspection
- name: Generate template for debugging
  template:
    src: app.conf.j2
    dest: /tmp/debug-app.conf
  when: debug_mode | default(false)
```

## Best Practices

### Template Organization
```bash
# Organize templates by role/service
templates/
├── nginx/
│   ├── nginx.conf.j2
│   ├── vhost.conf.j2
│   └── ssl.conf.j2
├── mysql/
│   ├── my.cnf.j2
│   └── backup.sh.j2
└── application/
    ├── app.conf.j2
    └── logging.conf.j2
```

### Variable Validation
```jinja2
{# Validate required variables #}
{% if server_name is not defined %}
{{ raise_error('server_name variable is required') }}
{% endif %}

{# Provide meaningful defaults #}
{% set app_port = app_port | default(8080) %}
{% set log_level = log_level | default('info') %}
```

### Security Considerations
```yaml
# Use vault for sensitive template variables
- name: Generate secure configuration
  template:
    src: app.conf.j2
    dest: /etc/app/app.conf
    mode: '0600'  # Restrict permissions
  vars:
    db_password: "{{ vault_db_password }}"
    api_key: "{{ vault_api_key }}"
  no_log: true  # Don't log sensitive data
```

### Performance Tips
```jinja2
{# Cache expensive operations #}
{% set sorted_hosts = groups['webservers'] | sort %}
{% for host in sorted_hosts %}
server {{ host }}
{% endfor %}

{# Use set for complex calculations #}
{% set total_memory = ansible_memtotal_mb %}
{% set buffer_size = (total_memory * 0.7) | int %}
buffer_pool_size = {{ buffer_size }}M
```
