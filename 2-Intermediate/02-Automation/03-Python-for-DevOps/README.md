# Python for DevOps: The Universal Glue

When shell scripts become too complex or require heavy API interaction, Python is the tool of choice. It bridges the gap between infrastructure management and software engineering, serving as the "Universal Glue" for modern platform engineering.

---

## 🚠 Modules Breakdown

### 1. [Python Environment and Basics](01-Python-Environment-and-Basics/README.md)
Master the foundation. Learn to isolate your automation with Virtual Environments (`venv`), manage dependencies with `pip`, and write robust logic using exception handling and type hints.

### 2. [System and File Operations](02-System-and-File-Operations/README.md)
Interact with the OS. Deep dive into the `os` and `sys` modules, execute shell commands safely with `subprocess`, and manage paths with the object-oriented `pathlib`.

### 3. [Working with Data: JSON and YAML](03-Working-with-Data-JSON-YAML/README.md)
Manipulate configuration at scale. Learn to parse and generate JSON and YAML manifests, work with DevOps-centric data structures (Dicts/Sets), and avoid security pitfalls.

### 4. [API Mastery with Requests](04-API-Mastery-with-Requests/README.md)
Connect your services. Master the `requests` library to talk to Slack, Jira, and GitHub. Implement robust error handling, retries, and authentication.

### 5. [Cloud Automation: Boto3 Deep Dive](05-Cloud-Automation-Boto3-Deep-Dive/README.md)
Automate the cloud. Understand the Boto3 SDK, compare "Client" vs. "Resource" patterns, handle sessions, and build lifecycle managers for AWS infrastructure.

---

## 📈 Learning Objectives
-   Isolate automation dependencies using virtual environments.
-   Execute and capture external shell commands safely.
-   Dynamically generate complex configuration manifests (K8s/Ansible).
-   Integrate automation with Slack, PagerDuty, and third-party APIs.
-   Manage multi-region/multi-account AWS infrastructure programmatically.
