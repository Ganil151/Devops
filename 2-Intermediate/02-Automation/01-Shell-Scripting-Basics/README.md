# Shell Scripting Basics

Master the fundamentals of Shell and Bash scripting. This folder contains basic scripts and guides to get you started with automation.

## 📂 Contents

- **hello.sh**: Basic echo script
- **hellouser.sh**: Interactive script using user input
- **MAChanger_How_To.txt**: Guide on changing MAC addresses (Networking automation example)
- **bashCustomizetion.txt**: Tips for customizing your Bash environment

## 🎯 Learning Objectives

1. Understand Shebang (#!) and script execution.
2. Use variables and user input.
3. Learn basic shell commands through scripting.
4. Practice environment customization.
