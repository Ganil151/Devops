# Shell Scripting Basics: The DevOps Glue

The shell is the native language of the server. Mastering it allows you to manipulate files, manage processes, and glue different tools together into a coherent automation pipeline.

---

## 🚠 Modules Breakdown

### 1. [Shell Environment and Execution](01-Shell-Environment-and-Execution/README.md)
Understand the shell-kernel hierarchy, the power of the shebang, and how execution permissions work in POSIX systems.

### 2. [Variables and Data Streams](02-Variables-and-Data-Streams/README.md)
Master the flow of data. Learn how to manage variables, handle standard streams (stdin, stdout, stderr), and use redirection/piping effectively.

### 3. [Logic and Flow Control](03-Logic-and-Flow-Control/README.md)
Add intelligence to your scripts. Use conditionals and loops to automate repetitive tasks and make decision-based actions.

### 4. [Shell Functions and Modularity](04-Shell-Functions-and-Modularity/README.md)
Keep your automation clean. Learn to build reusable functions, handle positional parameters, and manage variable scope with `local`.

### 5. [Robust Scripting and Error Handling](05-Robust-Scripting-and-Error-Handling/README.md)
Build production-grade scripts. Learn the Fail-Fast mechanism (set -euo pipefail), signal traps, and debugging techniques.

---

## 📈 Learning Objectives
-   Execute shell scripts with proper permissions and environments.
-   Redirect and pipe data between commands and files.
-   Implement complex logic using `if`, `case`, `for`, and `while`.
-   Write modular code using functions and libraries.
-   Apply strict error handling to prevent catastrophic script failures.
