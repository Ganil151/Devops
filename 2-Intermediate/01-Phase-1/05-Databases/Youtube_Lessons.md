# 📺 YouTube Lessons: Databases for DevOps

Learn to manage and scale databases within a modern DevOps workflow.

---

## 🐘 Relational Databases (Postgres & MySQL)

*   **[PostgreSQL DevOps Tutorial - Backup & Scaling](https://www.youtube.com/watch?v=hiKPPy582vg)**
    *   *Focus*: Managing state, migrations, and high availability for SQL databases.
*   **[AWS RDS Tutorial - Managed Database Services](https://www.youtube.com/watch?v=tK9Oc6AEnR4)**
    *   *Focus*: Deploying, backing up, and monitoring RDS instances on AWS.

## 🧊 NoSQL & Caching

*   **[MongoDB for DevOps - Deployment Patterns](https://www.youtube.com/watch?v=RR25S8UvPik)**
    *   *Focus*: Clustering, sharding, and managing NoSQL at scale.
*   **[Redis Crash Course - Caching Strategies](https://www.youtube.com/watch?v=gS8H0VvVfIs)**
