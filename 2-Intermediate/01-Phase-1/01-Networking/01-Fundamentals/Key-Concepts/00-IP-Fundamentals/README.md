# 🔢 Module 00: IP Fundamentals

## 📖 Overview
The Internet Protocol (IP) represents the address system of the digital world. Every device connected to a network needs an IP address to send and receive data. This module covers the core mechanics of IPv4 and IPv6, address classes, and the difference between public and private spaces.

## 🎓 Learning Objectives
- ✅ Understand the structure of **IPv4 (32-bit)** and **IPv6 (128-bit)** addresses.
- ✅ Differentiate between **Public IPs** and **Private IPs** (RFC 1918).
- ✅ Master the concept of **Static vs. Dynamic** IP assignment.
- ✅ Understand **Loopback** and **Broadcast** addresses.

## 🔑 Key Concepts
### 1. The IPv4 Address
Four "octets" (groups of 8 bits) separated by dots.
Example: `192.168.1.1`

### 2. Private IP Ranges (RFC 1918)
These ranges are not routable on the public internet:
- `10.0.0.0 - 10.255.255.255`
- `172.16.0.0 - 172.31.255.255`
- `192.168.0.0 - 192.168.255.255`

### 3. IPv6: The Future
Hexadecimal notation. Provides enough addresses for every grain of sand on earth.
Example: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`
