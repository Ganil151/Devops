# 🗝️ Key Networking Concepts

This directory contains the foundational building blocks of all modern communication.

## 📌 Core Pillar Summary

| Concept | Purpose | Analogy |
| :--- | :--- | :--- |
| **IP Addressing** | Identification of a machine. | Your physical home address. |
| **MAC Addressing** | Identification of the hardware. | Your Social Security Number. |
| **Subnetting** | Isolation and organization. | Different floors in an apartment building. |
| **Routing** | Path selection between networks. | A GPS choosing the fastest freeway. |
| **DNS** | Name-to-IP resolution. | A phone book or contact list. |
| **DHCP** | Dynamic configuration. | A concierge handing out room keys. |

---

## 🏗️ The Networking Mindset
When troubleshooting or designing, always think in **Layers**. If the "Physcial" layer (the wire) is broken, the "Application" layer (the website) will never work. Always troubleshoot from the bottom up.
