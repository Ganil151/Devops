# Systemd Unit File Template: Application Service
# Path: /etc/systemd/system/myapp.service

[Unit]
Description=My Python DevOps Application
After=network.target

[Service]
Type=simple
User=appuser
Group=appgroup

# Environment Variables
Environment=PORT=8080
Environment=ENV=production

# The Command to Run
ExecStart=/usr/bin/python3 /opt/myapp/app.py

# Restart Policy (Critical for Self-Healing)
Restart=on-failure
RestartSec=5s

# Logging
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target

---

# Linux Signal Reference Table

| Signal | Name | DevOps Use Case |
| :--- | :--- | :--- |
| 1 | `SIGHUP` | Reload configuration files without stopping the service. |
| 2 | `SIGINT` | Interrupt (CTRL+C). Graceful stop. |
| 9 | `SIGKILL` | Force stop immediately. Use as a LAST resort. |
| 15 | `SIGTERM` | Default termination signal. Requests process to cleanup and exit. |
| 10/12| `SIGUSR1/2`| Application-defined behavior (e.g., rotating logs manually). |
