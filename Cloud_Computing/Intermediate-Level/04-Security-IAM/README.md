# Security & Identity Access Management (IAM)

Comprehensive guides on securing cloud infrastructure, managing identities, and handling sensitive data.

## Module Overview

This module covers the core security pillars required for a production-ready cloud environment.

### 1. [AWS IAM Comprehensive Guide](aws-iam-comprehensive.md)
Foundational knowledge of IAM users, groups, roles, and basic policies. Start here if you are new to AWS security.

### 2. [Advanced Authentication & Authorization Strategies](auth-deep-dive.md)
Deep dive into multi-account strategies, permission boundaries, OIDC for CI/CD, and Cognito vs. Entra ID.

### 3. [Secrets Management Best Practices](secrets-best-practices.md)
How to securely store and rotate API keys, database credentials, and certificates using AWS Secrets Manager and SSM Parameter Store.

### 4. [Hands-on Cognito Guide (Console & CLI)](cognito-hands-on.md)
Practical guide to setting up user pools, managing users, and configuring the Hosted UI for application authentication.

## Learning Path
1. **Beginner**: Understand IAM Users and Roles in the Comprehensive Guide.
2. **Intermediate**: Implement Cross-Account access and OIDC.
3. **Advanced**: Automate secret rotation and implement Zero Trust architectures.
