# Cloud Computing Intermediate Level

Advanced cloud services, networking, security, and DevOps integration across major cloud platforms.

## Learning Path Overview

### 01. Advanced Compute Services
- Container services (ECS, AKS, GKE)
- Serverless computing (Lambda, Functions, Cloud Functions)
- Auto-scaling and load balancing
- High availability and fault tolerance

### 02. Networking and VPC
- Advanced virtual networking concepts
- VPC peering and transit gateways
- Hybrid connectivity (VPN, ExpressRoute, Interconnect)
- Network security and segmentation

### 03. Security and IAM
- Advanced identity and access management
- Multi-factor authentication and SSO
- Encryption and key management
- Compliance and governance frameworks

### 04. DevOps Integration
- CI/CD pipelines in the cloud
- Infrastructure as Code (Terraform)
- [AWS Lambda (Intermediate)](14-Serverless-Lambda/README.md)
- [Networking & Edge Services](15-Networking-Edge-Services/README.md)
- [Governance & Compliance](16-Governance-Compliance/README.md)
- Container orchestration and Kubernetes

### 05. Monitoring and Logging
- Cloud-native monitoring solutions
- Log aggregation and analysis
- Performance monitoring and alerting
- Cost monitoring and optimization

### 06. Load Balancing
- Advanced load balancing strategies
- Application and network load balancers
- Global load balancing and CDN
- Health checks and failover mechanisms

## Prerequisites
- Completed Beginner Level Cloud Computing
- Solid understanding of networking concepts
- Experience with Linux/Windows administration
- Basic programming or scripting knowledge

## Learning Objectives
By completing this level, you will:
- Deploy and manage advanced compute services
- Design secure and scalable network architectures
- Implement comprehensive security and compliance measures
- Integrate cloud services with DevOps workflows
- Monitor and optimize cloud infrastructure performance
- Configure advanced load balancing and traffic management
