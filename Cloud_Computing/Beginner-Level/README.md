# Cloud Computing Beginner Level

Introduction to cloud computing fundamentals, major cloud providers, and basic services.

## Learning Path Overview

### 01. Cloud Fundamentals
- Cloud computing concepts and definitions
- Service models (IaaS, PaaS, SaaS)
- Deployment models (Public, Private, Hybrid)
- Benefits and challenges of cloud adoption

### 02. AWS Basics
- AWS core services and console navigation
- EC2, S3, and basic compute/storage services
- IAM fundamentals and basic security
- Basic networking and VPC concepts
- [AWS Lambda Fundamentals](02-AWS-Basics/Lambda/README.md)

### 03. Azure Basics
- Azure portal and core services
- Virtual machines and storage accounts
- Resource groups and subscriptions
- Basic identity and access management

### 04. GCP Basics
- Google Cloud console and core services
- Compute Engine and Cloud Storage
- Projects and billing concepts
- Basic security and access controls

### 05. Basic Networking
- Cloud networking fundamentals
- Virtual networks and subnets
- Security groups and firewalls
- Basic load balancing concepts
- [API Gateway & CloudFront](15-Networking-Edge-Services/README.md)

### 06. Storage Fundamentals
- Cloud storage types and use cases
- Object, block, and file storage
- Backup and disaster recovery basics
- Data transfer and migration concepts

## Prerequisites
- Basic IT and networking knowledge
- Understanding of virtualization concepts
- Familiarity with command line interfaces
- Basic understanding of web technologies

## Learning Objectives
By completing this level, you will:
- Understand cloud computing fundamentals and benefits
- Navigate major cloud provider consoles and services
- Deploy basic compute and storage resources
- Configure basic networking and security settings
- Understand cloud pricing and billing models
- [AWS Lambda (Intermediate)](14-Serverless-Lambda/README.md)
- [Governance & Compliance (AWS Config)](16-Governance-Compliance/README.md)
