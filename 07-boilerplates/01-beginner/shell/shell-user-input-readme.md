# Boilerplates: User Input

Interactive automation prompts for safe deployments.

## Available Boilerplates

### 1. Environment Selector
**File**: `boilerplate_environment_selector.sh`

**Purpose**: Interactive deployment environment selection

**Usage**:
```bash
./boilerplate_environment_selector.sh
```

### 2. Terraform Destroy Guard
**File**: `boilerplate_terraform_destroy_guard.sh`

**Purpose**: Prevent accidental infrastructure deletion

**Usage**:
```bash
 ./boilerplate_terraform_destroy_guard.sh production
```
