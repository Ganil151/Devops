# Boilerplates: File Permissions

Security and access control scripts for DevOps workflows.

## Available Boilerplates

### 1. Ansible Key Setup
**File**: `boilerplate_ansible_key_setup.sh`

**Purpose**: Fix permissions for Ansible files and SSH keys

**Usage**:
```bash
./boilerplate_ansible_key_setup.sh
```

---

### 2. Script Auditor
**File**: `boilerplate_script_auditor.sh`

**Purpose**: Security compliance audit

**Usage**:
```bash
./boilerplate_script_auditor.sh
```

---

### 3. Deployment Artifact Protector
**File**: `boilerplate_deployment_artifact_protector.sh`

**Purpose**: Make build artifacts immutable

**Usage**:
```bash
./boilerplate_deployment_artifact_protector.sh ./dist
```
