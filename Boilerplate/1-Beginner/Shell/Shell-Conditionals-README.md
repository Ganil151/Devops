# Boilerplates: Conditionals

Decision-driven automation scripts.

## Available Boilerplates

### 1. Container Monitor
**File**: `boilerplate_container_monitor.sh`

**Purpose**: Auto-restart stopped containers

**Usage**:
```bash
./boilerplate_container_monitor.sh myapp
```
