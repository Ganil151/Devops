# Boilerplates: Finally Scripting

Complete automation workflows combining multiple shell concepts.

## Available Boilerplates

### 1. CI/CD Runner
**File**: `boilerplate_cicd_runner.sh`

**Purpose**: Full pipeline - Lint → Build → Test → Deploy

**Usage**:
```bash
./boilerplate_cicd_runner.sh
```

---

### 2. Disaster Recovery
**File**: `boilerplate_disaster_recovery.sh`

**Purpose**: Database backup to S3 with verification

**Usage**:
```bash
./boilerplate_disaster_recovery.sh
```

---

### 3. Infrastructure Reporter
**File**: `boilerplate_infrastructure_reporter.sh`

**Purpose**: Generate compliance reports

**Usage**:
```bash
./boilerplate_infrastructure_reporter.sh
```
