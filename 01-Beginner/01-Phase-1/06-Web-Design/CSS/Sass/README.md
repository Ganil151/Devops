# 💅 Sass: Syntactically Awesome Style Sheets
*Extending CSS with Logic and Variables*

---

## 📖 Overview
Sass is a CSS pre-processor language that helps to keep things organized and allows you to create style sheets faster.

---

## 🏗️ Technical Pillars

### 1. Variables (`$`)
Store colors, fonts, or any CSS value you want to reuse.
`$primary-color: #333;`

### 2. Nesting
Nesting selectors inside one another to follow the HTML hierarchy.

### 3. Mixins (`@mixin`)
Groups of CSS declarations that you can reuse throughout your site.
