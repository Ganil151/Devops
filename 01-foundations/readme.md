# 🎓 The SRE Beginner’s Academy: Five Core Pillars

> **"A Junior DevOps engineer knows how to use the tools. A Senior Architect understands the foundations that sustain the tools."**

Welcome to your structured journey into the world of Site Reliability Engineering and DevOps. This workspace has been meticulously audited and organized into **Five Core Pillars**. Each pillar represents a critical layer of the modern technology stack.

---

## 🏛️ The Five Core Pillars

### 1. [🐧 Linux Engineering](./01-Linux-Engineering/HUMAN_GUIDE.md)
*Master the Kernel, the Filesystem, and the Permissions that power the world.*
- **Key Concept**: Everything is a file.
- **Goal**: Move from the GUI to the Command Line.

### 2. [🌐 Network Protocols](./02-Network-Protocols/HUMAN_GUIDE.md)
*Understand how data shakes hands across the internet.*
- **Key Concept**: The OSI Model and DNS.
- **Goal**: Troubleshoot connectivity like a pro.

### 3. [🛠️ Git Version Control](./03-Git-Version-Control/HUMAN_GUIDE.md)
*The Time Machine for your code and infrastructure.*
- **Key Concept**: Branching, Merging, and the Source of Truth.
- **Goal**: Collaborate on complex systems without fear.

### 4. [🤖 Scripting & Automation](./04-Scripting-Automation/HUMAN_GUIDE.md)
*Let the robots do the boring work.*
- **Key Concept**: Bash Glue and Python Logic.
- **Goal**: Write idempotent code that manages thousands of servers.

### 5. [🐳 Foundational Containers](./05-Foundational-Containers/HUMAN_GUIDE.md)
*Package your world into immutable artifacts.*
- **Key Concept**: The Client-Server Daemon and Layers.
- **Goal**: Ship production-grade software that works everywhere.

---

## 🚀 How to use this Academy
1.  **Follow the Order**: The pillars are numbered logically. Linux (1) and Networking (2) are the ground floors. Scripting (4) and Containers (5) are the skyscrapers built on top of them.
2.  **Synthesis**: Every pillar has a `HUMAN_GUIDE.md` that tells the story of that topic.
3.  **Assessments**: Each folder has an `Assessment/` sub-folder. Do not move to the next pillar until you pass the quiz!
4.  **Hands-on**: Check the `Scripts/` and `Reference/` folders within each pillar for real-world examples.
