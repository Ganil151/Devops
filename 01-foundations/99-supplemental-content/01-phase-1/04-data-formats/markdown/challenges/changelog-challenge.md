# 🛠️ Markdown Challenge: The Changelog Standard

**Scenario**: Your team has just finished a major refactor of the Data Formats module. You need to document these changes for the other engineers following the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) standard.

**Task**: Create a `CHANGELOG.md` file that captures the work done today.

## Required Sections:
1. **Added**: List the new modules added (TOML, Markdown, etc.).
2. **Fixed**: List the linting fixes and relative paths.
3. **Removed**: List any hollow placeholder folders that were cleared.

## Deliverable:
Save your properly formatted markdown file as `CHANGELOG_GOAL.md` in the `solutions/` folder.
