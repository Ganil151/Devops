## 🏗️ Technical Standards (The "Orchestration Way")

Every module in this phase must follow these rules:

1.  **Junior vs Engineer Comparison**: Contrast manual scripts with containerized reproducibility.
2.  **Infrastructure Analogies**: Use the "Shipping Container," "Warehouse," and "Cattle vs Pets" models.
3.  **Security-First**: Emphasize non-root users, slim base images, and secret management.
4.  **Optimized Layers**: Teach proper `COPY` and `RUN` ordering for build efficiency.
5.  **Ephemeral Mindset**: Reinforce that containers can (and will) be destroyed at any moment.
