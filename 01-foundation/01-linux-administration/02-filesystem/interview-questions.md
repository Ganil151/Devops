# Interview Questions: Linux Filesystem

## 🟢 Beginner Level

### 1. What is the difference between `/bin` and `/usr/bin`?
**Answer**: Historically, `/bin` contained essential binaries needed to boot the system or repair it in single-user mode. `/usr/bin` contained non-essential binaries for users. In modern distros, they are often symbolically linked to each other.

### 2. Where are system log files typically stored?
**Answer**: System logs are stored in `/var/log`. Common files include `/var/log/syslog` (general logs), `/var/log/auth.log` (security/login logs), and `/var/log/dmesg` (kernel ring buffer).

### 3. What is the purpose of the `/etc` directory?
**Answer**: The `/etc` directory contains all the system-wide configuration files. It is where you configure services like SSH, Nginx, and user accounts.

---

## 🟡 Intermediate Level

### 4. What is a "Mount Point"?
**Answer**: A mount point is a directory in the Linux filesystem tree that serves as an entry point for a storage device (disk partition, NFS share, USB). When a device is "mounted," its contents become accessible at that directory.

### 5. Explain the importance of `/proc`.
**Answer**: `/proc` is a virtual (pseudo) filesystem. It doesn't exist on disk; it is generated by the kernel in memory. it provides an interface to internal kernel data structures, allowing users to view system stats (like CPU, RAM, Uptime) and process information.

### 6. What is the `sticky bit` on `/tmp`?
**Answer**: The sticky bit (represented as `t` in `drwxrwxrwt`) ensures that even though everyone can write to `/tmp`, only the owner of a file (or root) can delete or rename it.

## 🔴 Advanced (DevOps/SRE) Level

### 7. What is an Inode, and what happens if you run out of them?
**Answer**: An Inode is a data structure that stores metadata about a file (except its name). Every filesystem has a fixed number of Inodes. If you run out (common when storing millions of tiny files), you cannot create new files even if there is plenty of disk space left.

### 8. How does Linux handle a file that is deleted while a process is still writing to it?
**Answer**: The file's directory entry is removed (it "disappears" from `ls`), but the data remains on disk as long as the process has an open file descriptor. Disk space is not reclaimed until the process closes the file or terminates. You can find these files using `lsof | grep deleted`.

### 9. Why is it a best practice to have a separate partition for `/var` or `/var/log`?
**Answer**: To prevent a "Denial of Service" via disk exhaustion. If an application starts looping and generates massive logs, it could fill up the root `/` partition. If `/var/log` is separate, the logs will hit a limit without crashing the entire OS or preventing root from logging in to fix it.
