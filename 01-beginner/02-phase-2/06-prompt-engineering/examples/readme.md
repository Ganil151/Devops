# 📖 Prompt Template Library

Welcome to the **Prompt Library**. This directory contains production-ready system prompts and persona templates designed for various DevOps scenarios.

## 🗃️ Available Templates

| Template | Persona | Use Case |
| :--- | :--- | :--- |
| **[Senior DevOps Engineer](./senior-devops-engineer.md)** | Principal Engineer | Code reviews, infrastructure debugging, and architecture advice. |
| **[Content Architect](./content-architect.md)** | Documentation Lead | Drafting technical guides, runbooks, and curriculum development. |
| **[Full-Stack Instructor](./full-stack-instructor.md)** | Technical Trainer | Explaining complex concepts to junior engineers or students. |

## 🛠️ How to Use

1. **Copy** the content of a template.
2. **Paste** it into the "System Prompt" (or the first message) of your AI tool.
3. **Provide context** for your specific task.
4. **Execute!**
