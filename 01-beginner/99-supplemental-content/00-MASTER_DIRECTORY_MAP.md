## 📚 Learning Path Structure

### The 3-Phase Progression

```
Phase 1: Foundations          Phase 2: Intermediate        Phase 3: Advanced
(Weeks 1-8)                   (Weeks 9-20)                 (Weeks 21-32)
│                             │                            │
├─ Windows Basics             ├─ Python Automation         ├─ Advanced CI/CD
├─ Data Formats               ├─ API Development           ├─ Kubernetes
├─ Software Stack             ├─ Nginx Configuration       ├─ FinOps
├─ Web Frameworks             ├─ Maven Build Tools         ├─ MCP (AI/LLM)
├─ Cloud Foundations          ├─ Basic CI/CD               └─ Blockchain
└─ Repository Management      ├─ Prompt Engineering
                              ├─ Observability
                              ├─ GitOps
                              ├─ Compliance as Code
                              └─ Container Security
```

### Learning Objectives by Phase

#### **Phase 1: Foundations** (6 modules, 463 files)
**Goal**: Build fundamental skills required for DevOps work

**You will learn**:
- Windows PowerShell for hybrid-cloud management
- Configuration file formats (JSON, YAML, TOML, XML)
- DevOps tooling ecosystem
- Web application frameworks
- Cloud provider basics (AWS, Azure, GCP)
- Version control systems

**Prerequisites**: None - start here if you're new to DevOps

---

#### **Phase 2: Intermediate** (10 modules, 600 files)
**Goal**: Develop automation and CI/CD capabilities

**You will learn**:
- Python and Bash automation scripting
- REST API design and implementation
- Web server configuration (Nginx)
- Java build automation (Maven)
- CI/CD pipeline fundamentals
- AI-assisted development (Prompt Engineering)
- Logging, metrics, and tracing
- GitOps workflows
- Policy as code
- Container security

**Prerequisites**: Complete Phase 1 or have equivalent experience

---

#### **Phase 3: Advanced** (5 modules, 117 files)
**Goal**: Master advanced DevOps practices and emerging technologies

**You will learn**:
- Advanced CI/CD patterns and optimization
- Container orchestration with Kubernetes
- Cloud cost optimization (FinOps)
- AI/LLM integration with MCP
- Blockchain for DevOps use cases

**Prerequisites**: Complete Phase 2 or have 2+ years DevOps experience
