# 🅱️ Bootstrap: Rapid Prototyping
*The Foundation of Standard Enterprise UIs*

---

## 📖 Overview
Bootstrap is an open-source CSS framework directed at responsive, mobile-first front-end web development. It contains CSS- and JavaScript-based design templates for typography, forms, buttons, navigation, and other interface components.

---

## 🏗️ Technical Pillars

### 1. The Grid System
A 12-column responsive layout based on Flexbox.
- `container`, `row`, `col-md-6`.

### 2. Built-in Components
- **Navbars**: Complex responsive menus out of the box.
- **Modals**: Easy pop-ups for confirmation or data entry.
- **Cards**: Containers for grouped content.
