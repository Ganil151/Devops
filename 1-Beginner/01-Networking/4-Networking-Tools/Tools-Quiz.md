# 🛠️ Networking Tools Quiz

Test your mastery of diagnostic, simulation, and scanning tools.

## Part 1: Simulators & Emulators

**1. What is the primary difference between Packet Tracer and GNS3?**
- A) Packet Tracer is more expensive.
- B) GNS3 allows you to simulate IoT devices.
- C) Packet Tracer simulates device behavior, while GNS3 emulates real OS images.
- D) GNS3 is made by Cisco.

**2. In Packet Tracer, what mode allows you to watch a packet travel hop-by-hop and inspect headers?**
- A) Real-time Mode
- B) Simulation Mode
- C) Inspection Mode
- D) Debug Mode

**3. Which cable type is required to connect a Router to another Router via Ethernet interfaces in Packet Tracer?**
- A) Straight-Through
- B) Console Cable
- C) Serial DCE
- D) Crossover

**4. To run GNS3 effectively, what is the recommended setup?**
- A) Run everything on your local Windows desktop directly.
- B) Use the GNS3 VM (Virtual Machine) to handle the emulation backend.
- C) Run it on a Raspberry Pi.
- D) Use only the web-based version.

## Part 2: Diagnostics & Scanning

**5. Which tool is best suited for "Deep Packet Inspection" and GUI analysis?**
- A) Tcpdump
- B) Nmap
- C) Wireshark
- D) Ping

**6. Which flag in `nmap` detects the Operating System of the target?**
- A) `-sS`
- B) `-O`
- C) `-p`
- D) `-v`

**7. If you want to capture packets on a headless Linux server via CLI, which tool is standard?**
- A) Wireshark
- B) SolarWinds
- C) Tcpdump
- D) Packet Tracer

**8. What does a "Three-Way Handshake" look like in Wireshark?**
- A) FIN -> ACK -> SYN
- B) SYN -> SYN-ACK -> ACK
- C) RST -> SYN -> FIN
- D) PSH -> URG -> FIN

---

## ✅ Answers

1. **C** (Packet Tracer simulates; GNS3 runs real code)
2. **B** (Simulation Mode)
3. **D** (Crossover - connecting like devices)
4. **B** (GNS3 VM is much more stable)
5. **C** (Wireshark)
6. **B** (`-O`)
7. **C** (Tcpdump)
8. **B** (SYN -> SYN-ACK -> ACK)
