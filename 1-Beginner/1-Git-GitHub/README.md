# Git & GitHub Fundamentals

This directory covers essential version control concepts using Git and GitHub.

## Learning Objectives

### Basic Commands

- Initialize a Git repository
- Stage and commit changes
- View commit history
- Undo changes

### Branching Strategies

- Create and manage branches
- Merge vs Rebase
- Resolve merge conflicts
- Git flow workflow

### GitHub Flow

- Forking workflow
- Pull requests and code reviews
- GitHub Actions basics
- Managing issues and projects

## Exercises

1. Create a new repository and make your first commit
2. Create a feature branch and merge it to main
3. Resolve a merge conflict
4. Contribute to an open-source project using fork & PR
