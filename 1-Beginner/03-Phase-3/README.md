# Phase 3: Automation Orchestration & Systems Mastery
*From Scripts to Scalable Software Factories*

Phase 3 is where individual automation skills (Shell, Python, Go) are orchestrated into comprehensive, automated delivery systems. You will learn how to build, ship, and run applications at scale while maintaining cost-efficiency and observability.

---

## 🗺️ Phase 3 Modules

### 🏗️ [01. CI/CD Foundations](./01-CI-CD-Foundations/README.md)
*Mastering the delivery pipeline: Jenkins, GitHub Actions, and GitLab CI.*
*   Continuous Integration & Deployment theory.
*   Pipelines as Code (Jenkinsfile, YAML).
*   Artifact Management (Nexus, Artifactory).

### 🐳 [02. Container Orchestration](./02-Container-Orchestration/README.md)
*Running applications in isolated, scalable environments.*
*   Docker Fundamentals & Architecture.
*   Multi-stage builds & Security.
*   Docker Compose for multi-container apps.

### 💰 [03. FinOps](./03-FinOps/README.md)
*The intersection of Cloud, Finance, and Engineering.*
*   Cloud billing & Cost visibility.
*   Budgeting & Resource optimization.

### 🔌 [04. MCP (Model Context Protocol)](./04-MCP/README.md)
*Modern agentic ecosystems and server architecture.*
*   MCP Architecture & Primitives.
*   Building Custom MCP Servers.

### ⛓️ [05. Blockchain Infrastructure](./05-Blockchain/README.md)
*Decentralized systems and node management.*
*   Blockchain Architecture & Node Types.
*   Infrastructure management for decentralized ops.

---

## 🎯 Learning Path Goal
By the end of Phase 3, you will be able to design a complete CI/CD pipeline that builds a Dockerized application, pushes it to a private registry, and manages its resource costs—all through automated code.
