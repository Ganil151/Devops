# Software Stack Foundations

Understanding the components that make up a modern software application is essential for DevOps.

## 📂 Core Concepts
- **Frontend**: The user interface (React, Vue, HTML/CSS).
- **Backend**: The business logic (Python, Java, Node.js).
- **Runtimes**: Environments where code executes (JVM, Python Interpreter, Node.js).
- **Frameworks**: Structures that support development (Django, Spring Boot, Express).
