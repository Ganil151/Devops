# 🏙️ ReactNative: Mobile React Standard
*Native App Engineering with JavaScript*

---

## 📖 Overview
ReactNative lets you build mobile apps using only JavaScript. It use the same design as React, letting you compose a rich mobile UI from declarative components.

---

## 🏗️ Technical Pillars

### 1. Basic Components
- `<View>`: Equivalent to `<div>`.
- `<Text>`: Required for all text strings.
- `<Image>`: Mobile-optimized image handling.

### 2. Styling (Yoga Engine)
ReactNative uses a subset of CSS via JavaScript objects. Layout is primarily handled via Flexbox.

### 3. Native Bridges
Access camera, GPS, and other hardware using native bridges or libraries like "Expo."
