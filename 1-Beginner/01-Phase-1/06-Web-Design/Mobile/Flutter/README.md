# 🦋 Flutter: Native High-Performance UI
*Extreme Graphics and Speed with Dart*

---

## 📖 Overview
Flutter is Google's UI toolkit for building beautiful, natively compiled applications for mobile, web, and desktop from a single codebase.

---

## 🏗️ Technical Pillars

### 1. Everything is a Widget
In Flutter, the UI is built from a tree of widgets. Even alignment is a widget.

### 2. Dart Programming Language
An object-oriented, class-tailored language with static typing and sound type-safety.

### 3. Skia Rendering Engine
Flutter paints every pixel directly on the screen, bypassing platform-specific widgets for consistent behavior.
