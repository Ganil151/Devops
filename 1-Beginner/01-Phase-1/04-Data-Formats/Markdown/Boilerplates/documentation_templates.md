# 📝 Markdown Boilerplates: Docs-as-Code Assets

This directory contains templates for professional DevOps documentation using GitHub Flavored Markdown.

## 1. ADR (Architectural Decision Record) Template
A standard for recording the "Why" behind infrastructure changes.

```markdown
# [ADR-XXXX] Title of the Decision

- **Status**: [Proposed | Accepted | Superseded]
- **Date**: YYYY-MM-DD
- **Author**: @username

## 1. Context
Provide a brief overview of the problem being solved. What system is being changed?

## 2. Decision
Detail the chosen solution. Use code blocks to show the target state.

## 3. Consequences
What are the trade-offs?
- **Pros**: List benefits (e.g., improved scalability).
- **Cons**: List drawbacks (e.g., increased cost).

## 4. Metadata
- **Tags**: #kubernetes #security #automation
```
