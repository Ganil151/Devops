# Boilerplates: Vim Crash Course

File permission and scheduling scripts.

## Available Boilerplates

### 1. SSH Key Securify
**File**: `boilerplate_ssh_key_securify.sh`

**Purpose**: Fix SSH key permissions (chmod 600)

**Usage**:
```bash
./boilerplate_ssh_key_securify.sh
```

---

### 2. Crontab Manager
**File**: `boilerplate_crontab_manager.sh`

**Purpose**: Schedule automated backups

**Usage**:
```bash
./boilerplate_crontab_manager.sh
```
