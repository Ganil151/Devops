# Functions - Boilerplate Scripts

## Overview
Demonstrates writing modular, reusable functions for common DevOps tasks.

## Scripts

### 1. `backup_util.py` - Archive Generator
**Purpose**: A module containing functions to compress directories and manage archives.

**DevOps Use Case**: 
- Automated backups before deployments.
- Log rotation and archival.

**Run:**
```bash
python backup_util.py
```

**Expected Output:**
```
INFO - Archiving temp_data...
INFO - Archive created: ...
INFO - Cleanup complete.
```
