# File Operations - Boilerplate Scripts

## Overview
Working with the filesystem using the modern `pathlib` library (preferred over `os.path`).

## Scripts

### 1. `log_rotator.py`
**Purpose**: Simulates a log rotation mechanism.

**DevOps Use Case**: 
- Preventing disk overflow.
- Managing application logs in non-containerized environments.

**Run:**
```bash
python log_rotator.py
```
