# 🧪 Python DevOps Testing Reference
*Version 1.0 | Ensuring Code Integrity in the Infrastructure Pipeline*

---

## 🏛️ Executive Summary
Infrastructure scripts often have immense "Destructive Power." Testing is not an optional extra; it is the safety brake that prevents a faulty script from deleting a production VPC. This guide covers unit testing, mocking cloud APIs, and CI integration.

---

## 🏗️ Technical Pillars: The Testing Stack

### 1. Pytest (The Industry Standard)
**Purpose**: A feature-rich testing framework that automates test discovery.
- **Fixture Pattern**: Use `@pytest.fixture` to setup a clean environment (e.g., a temp directory) before each test.

### 2. Mocking (External Dependencies)
**Mechanism**: Replacing slow or dangerous API calls (AWS/Azure) with fake objects.
- **Standard**: Use `unittest.mock` or `moto` (specifically for AWS).
- **Snippet**:
```python
from unittest.mock import patch

@patch("subprocess.run")
def test_cleanup_script(mock_run):
    mock_run.return_value.returncode = 0
    # Your logic...
    assert mock_run.called
```

## ⚙️ Coverage & Quality Gate

- **`pytest-cov`**: Generates a coverage report. 
- **SRE Rule**: Aim for 100% coverage on **Side-Effect logic** (the parts that actually delete or modify things).
- **Linters**: Use `flake8` or `ruff` to ensure code style consistency across the team.

---

## 🛡️ SRE Global Patterns: Integration Testing

While Unit Tests test individual functions, **Integration Tests** test the full script against a "Sandbox" environment.
1. **The Sandbox**: Create an AWS Sub-Account or GCP Project exclusively for testing.
2. **Automated Teardown**: Ensure every integration test cleans up all created resources, regardless of pass or fail.

---

## 🚀 Troubleshooting Scenario: "Flaky Tests"
**Scenario**: Your tests pass locally but fail randomly in GitHub Actions.
- **Root Cause**: Often **Race Conditions** or **Hidden Dependencies** on local files.
- **Solution**: Use `pytest --random-order` to find tests that depend on the state left by previous tests.
