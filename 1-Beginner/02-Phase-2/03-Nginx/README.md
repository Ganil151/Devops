# Nginx Web Server

Nginx is a high-performance web server, reverse proxy, and load balancer.

## 📂 Key Topics
- **Reverse Proxy**: Shielding backend servers from direct internet exposure.
- **Load Balancing**: Distributing traffic across multiple server instances.
- **SSL/TLS Termination**: Handling encryption at the edge.
- **Static Content Hosting**: Efficiently serving images, CSS, and JS.
