# Linux Basics for DevOps

This directory covers essential Linux commands and concepts needed for DevOps practitioners.

## Learning Objectives

### File System

- Navigate the Linux filesystem
- File permissions and ownership
- Basic file operations (create, copy, move, delete)
- Find and search files

### User Permissions

- Understanding users and groups
- File permissions (chmod, chown, chgrp)
- Sudo and root access
- Managing user accounts

### Process Management

- View running processes (ps, top, htop)
- Process control (kill, killall, pkill)
- Background and foreground processes
- System monitoring tools

## Exercises

1. Navigate through the filesystem and list directory contents
2. Create a new user and set appropriate permissions
3. Monitor system resources and manage processes
4. Write a simple shell script to automate a task
