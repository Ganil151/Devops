## 🎤 Top 20 Beginner Linux Interview Questions

1. **What is Linux?**
   - *Answer*: Linux is an open-source, Unix-like operating system kernel. It serves as the foundation for many distributions (Ubuntu, CentOS, Debian) used in servers and cloud environments.

2. **How do you find the current directory you are in?**
   - *Answer*: Using the `pwd` (print working directory) command.

3. **What command is used to list files in a directory?**
   - *Answer*: The `ls` command. Common flags: `-l` (long format), `-a` (show hidden files).

4. **How do you create a new directory?**
   - *Answer*: Using the `mkdir` command.

5. **How do you create an empty file?**
   - *Answer*: Using the `touch` command.

6. **What is the difference between `absolute` and `relative` paths?**
   - *Answer*: An **absolute path** starts from the root (`/`) (e.g., `/var/log`). A **relative path** starts from the current directory (e.g., `../logs`).

7. **How do you delete a file?**
   - *Answer*: Using the `rm` command.

8. **How do you delete a non-empty directory?**
   - *Answer*: Using `rm -rf <directory_name>`. (Be careful!)

9. **What command is used to copy files?**
   - *Answer*: The `cp` command.

10. **What command is used to move or rename files?**
    - *Answer*: The `mv` command.

11. **How do you view the contents of a file?**
    - *Answer*: Using `cat`, `less`, `more`, or `tail`.

12. **What does the `sudo` command do?**
    - *Answer*: It allows a permitted user to execute a command as the superuser (root) or another user.

13. **How do you search for a string in a file?**
    - *Answer*: Using the `grep` command.

14. **What is the `/root` directory?**
    - *Answer*: It is the home directory for the root user. Note: it is different from the `/` (root) directory.

15. **How do you change directory to your home folder?**
    - *Answer*: Simply type `cd` or `cd ~`.

16. **What command shows you the manual for another command?**
    - *Answer*: The `man` command (e.g., `man ls`).

17. **How do you check which user you are logged in as?**
    - *Answer*: Using the `whoami` command.

18. **What is the `.` and `..` in a directory listing?**
    - *Answer*: `.` represents the current directory, and `..` represents the parent directory.

19. **How do you clear the terminal screen?**
    - *Answer*: Using the `clear` command or `Ctrl+L`.

20. **What is the purpose of the `man` command?**
    - *Answer*: To display the reference manual for other commands.
