## ✅ Checklists

### Pre-Launch Checklist (Consulting)
- [ ] 3 case studies written with metrics
- [ ] LinkedIn profile optimized
- [ ] Professional headshot
- [ ] GitHub portfolio updated
- [ ] Simple website or landing page live
- [ ] Calendly set up for discovery calls
- [ ] Invoicing system configured (Wave, FreshBooks)
- [ ] Contract template ready (Bonsai, DocuSign)
- [ ] Upwork profile 100% complete
- [ ] Toptal application submitted
- [ ] Email signature with links
- [ ] Business email set up

---

### Discovery Call Checklist
**Before the Call**:
- [ ] Research the company (website, LinkedIn, Crunchbase)
- [ ] Review their tech stack (job postings, blog, GitHub)
- [ ] Prepare 5-10 questions
- [ ] Test Zoom/Google Meet link
- [ ] Have notepad ready

**During the Call**:
- [ ] Introduction (2 min): Who you are, what you do
- [ ] Their challenge (10 min): Let them talk, take notes
- [ ] Your experience (5 min): Share relevant case study
- [ ] Approach discussion (8 min): How you'd solve it
- [ ] Logistics (5 min): Timeline, budget, next steps

**After the Call**:
- [ ] Send follow-up email within 24 hours
- [ ] Add to CRM with notes
- [ ] Send proposal within 48-72 hours
- [ ] Follow up if no response in 3-5 days

---

### Content Creation Checklist
**Before Writing**:
- [ ] Choose SEO keyword (AnswerThePublic, Ahrefs)
- [ ] Research top 5 competing articles
- [ ] Create outline with H2/H3 headers
- [ ] Gather code examples and test them
- [ ] Create diagrams if needed

**During Writing**:
- [ ] Hook in first 2 sentences
- [ ] Context: Why this matters
- [ ] Step-by-step tutorial
- [ ] Code examples with explanations
- [ ] Troubleshooting section
- [ ] Conclusion with next steps

**Before Publishing**:
- [ ] Proofread with Grammarly
- [ ] Check readability (Hemingway Editor)
- [ ] Test all code examples
- [ ] Add meta description
- [ ] Create social media graphics
- [ ] Schedule promotion posts

**After Publishing**:
- [ ] Share on LinkedIn with commentary
- [ ] Post Twitter thread
- [ ] Cross-post to Dev.to
- [ ] Submit to relevant subreddits
- [ ] Email your list
- [ ] Respond to comments within 24 hours

---

### Product Launch Checklist
**2 Weeks Before**:
- [ ] MVP feature-complete
- [ ] Documentation written
- [ ] Demo video recorded
- [ ] Landing page live
- [ ] Pricing finalized
- [ ] Stripe/payment processing set up
- [ ] Beta users recruited (20+)

**1 Week Before**:
- [ ] Product Hunt submission prepared
- [ ] Launch blog post written
- [ ] Social media graphics created
- [ ] Email announcement drafted
- [ ] Press kit ready (if applicable)

**Launch Day**:
- [ ] Submit to Product Hunt (12:01 AM PST)
- [ ] Post on Hacker News (Show HN)
- [ ] Share on Twitter, LinkedIn
- [ ] Post in relevant subreddits
- [ ] Email your list
- [ ] Respond to every comment/question

**Week After Launch**:
- [ ] Thank beta users
- [ ] Send personal emails to early customers
- [ ] Request testimonials
- [ ] Analyze metrics (signups, conversions)
- [ ] Plan next features based on feedback
