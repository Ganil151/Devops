# Kubernetes Learning Path

Welcome to the comprehensive Kubernetes learning guide. This repository is organized into three levels to help you master Kubernetes step-by-step.

## 🎓 Learning Levels

### 🟢 [1. Beginner Level](Beginner/README.md)
**Start Here!**
- **Goal**: Understand the basics and deploy your first app.
- **Topics**: Cluster Architecture, Pods, Nodes, Services, Kubectl.
- **Prerequisites**: Basic Linux and Docker knowledge.

### 🟡 [2. Intermediate Level](Intermediate/README.md)
**Level Up!**
- **Goal**: Manage real-world applications and configuration.
- **Topics**: Deployments, ConfigMaps, Secrets, Namespaces, Storage, Ingress.
- **Prerequisites**: Understanding of Pods and Services.

### 🔴 [3. Advanced Level](Advanced/README.md)
**Master Class!**
- **Goal**: Production operations, security, and deep internals.
- **Topics**: StatefulSets, RBAC, Network Policies, Control Plane, Autoscaling, EKS.
- **Prerequisites**: Comfort with Deployments and basic networking.

## 🛠 Directory Structure
- `Beginner/`: Core concepts
- `Intermediate/`: Application management
- `Advanced/`: Production & Security
- `Images/`: Architecture diagrams
- `Youtube_Lessons/`: Supplementary material
