# 🕵️ Part 3: Distributed Tracing & APM

In a microservice world, a single user request might touch 10 different services. Metrics and logs can't easily connect the dots. Distributed Tracing allows you to follow the "path" of a request across the entire system.

---

## 📂 Modules in this Part

### 1. [04-Tracing-Foundations](./04-tracing-foundations/readme.md)
The pinnacle of observability.
- **Trace & Spans**: Understanding the tree structure of a request.
- **Context Propagation**: How to pass IDs between services.
- **APM (Application Performance Monitoring)**: Using tools like Jaeger, Zipkin, or AWS X-Ray.
