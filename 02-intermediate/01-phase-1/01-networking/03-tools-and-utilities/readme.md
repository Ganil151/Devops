# 🛠️ Part 3: Tools and Utilities

This module provides the "DevOps Toolkit" for networking. We focus on the practical tools used daily for troubleshooting, monitoring, and cloud infrastructure management.

---

## 📖 Overview

A networking expert is only as good as their tools. In this part, we cover:

- **Packet Sniffing**: Deep diving into traffic with Wireshark and Tcpdump.
- **Network Discovery**: Scanning for security vulnerabilities and active hosts with Nmap.
- **Cloud Infrastructure**: Mastering AWS VPC and interconnected cloud networks.
- **Monitoring**: Real-time observability of network health and flow logs.

## 🧰 Key Tools Covered

### 1. Wireshark & Tcpdump

- Capturing raw packets for "Ground Truth" analysis.
- Filtering massive capture files to find specific retransmissions or latency issues.

### 2. Nmap & Netstat

- **Nmap**: The gold standard for port scanning and inventory discovery.
- **Netstat/SS**: Checking active sockets and process-to-port mappings on a live server.

### 3. Cloud Networking Management

- **VPC Fundamentals**: Subnets, IGWs, and NAT Gateways.
- **Connectivity**: Peering, Transit Gateways, and Direct Connect.

### 4. Troubleshooting Workflow

- The "Step-by-Step" guide to diagnosing a broken connection from Layer 1 to Layer 7.
