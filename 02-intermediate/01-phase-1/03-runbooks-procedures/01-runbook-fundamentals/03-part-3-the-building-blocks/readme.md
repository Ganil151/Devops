---

## 🚀 The Quality Loop

1.  **Incident**: Something breaks.
2.  **Execution**: Follow the runbook.
3.  **Observation**: Was something missing? Was a step confusing?
4.  **Update**: Fix the runbook *immediately* after the incident.
5.  **Validation**: Test the new doc in a scheduled "Gameday."

---
## 🎓 Senior SRE Pro-Tip
"Never let a runbook get more than 6 months old without being tested. If it hasn't been run in a gameday, assume it will fail in an emergency."
