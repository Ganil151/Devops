# Azure Compute Engine & Container Instances

Information on Azure Virtual Machines (VMs) and Azure Container Instances (ACI).

## Azure VMs
- **Instance Types**: General purpose, Compute optimized, Memory optimized, etc.
- **Scalability**: Virtual Machine Scale Sets (VMSS).
- **IaC**: Use Bicep or Terraform (`azurerm_linux_virtual_machine`).

## Azure Container Instances (ACI)
- Serverless container execution.
- Fast startup, no orchestrator management.
- Ideal for small, isolated workloads.
