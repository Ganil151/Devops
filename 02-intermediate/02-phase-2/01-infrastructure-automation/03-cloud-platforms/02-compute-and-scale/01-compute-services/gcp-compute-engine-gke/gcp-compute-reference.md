# GCP Compute Engine & GKE

Information on Google Compute Engine (GCE) and Google Kubernetes Engine (GKE).

## Google Compute Engine (GCE)
- **Technical Edge**: Live migration of VMs during maintenance.
- **Customization**: Custom machine types (exact vCPU/RAM).
- **IaC**: Terraform (`google_compute_instance`).

## Google Kubernetes Engine (GKE)
- Industry-leading managed Kubernetes.
- Autopilot mode for fully managed operations.
