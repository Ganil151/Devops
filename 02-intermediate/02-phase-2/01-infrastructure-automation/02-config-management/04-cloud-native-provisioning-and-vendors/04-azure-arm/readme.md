# 🔷 Azure Resource Manager (ARM) Templates

## 📋 Overview
ARM templates are JSON files that define the infrastructure and configuration for your Azure solutions. They use a declarative syntax, letting you state what you intend to deploy without having to write the sequence of programming commands to create it.

## 📂 Module Structure

### 🏆 [Advanced Level](./advanced/readme.md)
