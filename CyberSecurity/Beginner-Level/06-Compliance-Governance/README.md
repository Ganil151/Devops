# Compliance and Governance

## Overview
Introduction to cybersecurity compliance frameworks, regulations, and governance principles.

## Learning Objectives
- Understand major compliance frameworks
- Learn regulatory requirements basics
- Implement basic governance processes
- Conduct compliance assessments

## Key Topics
1. Compliance Frameworks (ISO 27001, NIST, SOC 2)
2. Regulatory Requirements (GDPR, HIPAA, PCI-DSS)
3. Security Governance Principles
4. Policy Development Basics
5. Audit Preparation
6. Risk Management Integration

## Hands-on Labs
- Compliance gap analysis
- Basic policy creation
- Audit checklist development
- Risk register maintenance

## Assessment
- Compliance framework comparison
- Policy development exercise
- Basic audit simulation
