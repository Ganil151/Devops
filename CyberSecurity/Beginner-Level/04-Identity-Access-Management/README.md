# Identity and Access Management (IAM)

## Overview
Fundamental concepts of identity management, authentication, and authorization.

## Learning Objectives
- Understand authentication vs authorization
- Learn password security best practices
- Implement basic access controls
- Configure multi-factor authentication

## Key Topics
1. Authentication Methods
2. Authorization Models (RBAC, ABAC)
3. Password Security and Policies
4. Multi-Factor Authentication (MFA)
5. Single Sign-On (SSO) Basics
6. Privileged Access Management

## Hands-on Labs
- Active Directory user management
- MFA setup and testing
- Password policy configuration
- Basic RBAC implementation

## Tools Covered
- Active Directory
- LDAP
- Google Authenticator/Authy
- Basic SSO solutions

## Assessment
- IAM policy design exercise
- Authentication method comparison
- Access control scenario implementation
