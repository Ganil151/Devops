# 🛠️ Phase 1: Systems Foundations (The Engineer's Bedrock)

## Goal
Master the fundamental systems that the cloud is built on. Without a deep understanding of Networking and Linux, automation becomes a black box of fragility.

## Modules
1. **01-Networking**: OSI Model, TCP/IP, DNS, Routing, and Troubleshooting.
2. **02-Linux Mastery**: Filesystem hierarchy, permissions, process management, and Shell scripting.
3. **03-Data-Serialization**: JSON, YAML, and TOML. The languages of configuration.
