# 🚀 Projects Showcase: Production-Ready Blueprints

> **"A senior engineer is defined not by the code they write, but by the systems they architect and the governance they enforce."**

This directory is the gallery for the most complex, end-to-end DevOps projects in the curriculum. These are not just snippets; they are full architectural blueprints designed to be **Production-Ready**, following strictly defined quality gates.

---

## 🏗️ Project Portfolio Architecture

### 0. [Governance: Standard Checklists](./00-Governance-Standard-Checklists/README.md)
The "Definition of Done" for all projects. This directory contains the quality gates for Infrastructure (IaC), CI/CD, Containerization, Security, and Observability. **Every project in this showcase is audited against these standards.**

### 1. [Enterprise Microservices Mesh](./01-Enterprise-Microservices-Mesh/README.md)
A globally distributed microservices architecture featuring:
- **Service Mesh**: Mutual TLS and advanced traffic routing via Istio.
- **GitOps**: Automated synchronization between Git and Kubernetes.
- **Infrastructure**: Multi-region EKS deployment via Terraform.

### 2. [Full-Stack Django & Next.js Backend API](./02-FullStack-Django-NextJS/README.md)
A modern boilerplate for building high-performance, secure web applications:
- **Frontend**: Next.js with Server-Side Rendering (SSR).
- **Backend**: Django REST Framework with standardized JWT authentication.
- **DevOps**: Docker-compose and K8s manifests for seamless environment parity.

### 3. [Spring PetClinic CI/CD Ecosystem](./03-Spring-PetClinic-CI-CD/README.md)
An enterprise Java delivery pipeline showcasing:
- **Build Automation**: Multi-module Maven builds.
- **CI/CD**: Sophisticated Jenkins pipelines with SonarQube quality gates.
- **Security**: Automated vulnerability scanning and image signed artifacts.
