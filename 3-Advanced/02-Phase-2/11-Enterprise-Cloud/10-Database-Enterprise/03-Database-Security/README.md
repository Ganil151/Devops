# Database Security

Advanced techniques for hardening and monitoring relational and NoSQL databases.

## Guides

### [Database Security Best Practices](db-security-best-practices.md)
Comprehensive guide on:
- IAM Database Authentication.
- Encryption at rest and in transit.
- Network isolation (Private subnets).
- Vulnerability scanning with GuardDuty.

## Security Controls Checklist
- [ ] No public access allowed.
- [ ] SSL/TLS enforced for all connections.
- [ ] KMS Encryption enabled for storage and backups.
- [ ] Least-privilege IAM policies for database access.
