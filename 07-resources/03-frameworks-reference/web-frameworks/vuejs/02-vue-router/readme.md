# 🗺️ Vue Router
*Seamless Navigation for Vue Apps*

---

## 📖 Overview
Vue Router is the official router for Vue.js. It integrates deeply with the Vue core to build single-page apps.

---

## 🏗️ Technical Pillars

### 1. Route Definitions
```javascript
const routes = [
  { path: '/', component: Home },
  { path: '/stats', component: Stats },
]
```

### 2. `<router-view>`
The placeholder where the current route's component is rendered.

### 3. Navigation Guards
Code that runs before a route change. Perfect for authentication checks.
