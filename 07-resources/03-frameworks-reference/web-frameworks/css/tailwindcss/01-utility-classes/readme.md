# 🌊 Tailwind CSS: Essential Utility Classes
*Speed-Building Layouts without Custom CSS*

---

## 📖 Overview
Tailwind operates on the principle that you should build your entire UI by composing small, single-purpose classes directly in your HTML.

---

## 🏗️ Technical Pillars

### 1. Spacing & Sizing
- **Margin**: `m-4`, `mx-2`, `mt-0`.
- **Padding**: `p-4`, `px-6`, `py-8`.
- **Width/Height**: `w-full`, `w-64`, `h-screen`.

### 2. Flexbox & Grid (Modern Layout)
- **Flex**: `flex`, `flex-col`, `justify-between`, `items-center`.
- **Grid**: `grid`, `grid-cols-3`, `gap-4`.

### 3. Typography & Color
- **Text**: `text-xl`, `font-bold`, `italic`.
- **Colors**: `bg-blue-500`, `text-gray-900`, `border-red-200`.
